Tempel seluruh daftar Anda. Setiap baris menjadi satu kegiatan, dan hasilnya bisa dicek sebelum ditambahkan.

Format yang dikenali
  • Awalan -, *, 1., atau [ ] dibuang otomatis. [x] menandai kegiatan sudah selesai.
  • Baris berakhiran : atau diawali # (dengan spasi) menjadi kategori untuk baris di bawahnya.
  • Per baris: #kategori, !tinggi !sedang !rendah, @harian, @bulanan, @senin,kamis. Semuanya opsional dan menimpa pengaturan di bawah.

    Kunci aplikasi (PIN)

    PIN melindungi token dan kata sandi sinkron serta menutup layar. Data kegiatan di perangkat tidak dienkripsi.

    Sinkron antar perangkat (GitHub Gist)

    1. Buat token (centang gist saja), lalu salin tokennya.
    2. Tempel di sini, buat kata sandi enkripsi (minimal 12 karakter), lalu ketuk Hubungkan. Ulangi di perangkat lain dengan token dan kata sandi yang sama. Data dienkripsi sebelum dikirim. Jika kata sandi lupa, data di cloud tidak bisa dibuka.

    Sinkron lama dinonaktifkan karena kini memakai enkripsi. Token Anda masih tersimpan, cukup isi kata sandi.

    Data tersimpan di browser perangkat ini. Untuk memindahkan ke perangkat lain, ekspor di sini lalu impor di sana.

    Impor akan mengganti seluruh data di perangkat ini.
